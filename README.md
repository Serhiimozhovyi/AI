# Course Analytics Dashboard

Простий AI-проєкт з пайплайном Database → Agent → Dashboard.

Беру дані з бази курсів (enrollments, платежі, відгуки, активність), рахую основні
метрики, і даю можливість поставити питання агенту, який відповідає на основі цих
даних через Gemini.

## Що тут є

- `config.py` — зчитує DATABASE_URL і GEMINI_API_KEY з `.env` (локально) або з
  Secrets (коли задеплоєно на Streamlit Cloud).
- `db.py` — усі запити до бази (тільки читання, нічого не змінюю і не видаляю).
- `agent.py` — збирає зведення по даних і питає Gemini, щоб отримати відповідь
  людською мовою + короткий підсумок стану платформи.
- `app.py` — сам dashboard на Streamlit: KPI-картки, графіки по курсах/доходу/
  аудиторії і поле для питання агенту.

## Як запустити

```bash
pip install -r requirements.txt
cp .env.example .env
```

Відкрий `.env` і встав свій `GEMINI_API_KEY` (DATABASE_URL там уже стоїть).

```bash
streamlit run app.py
```

Відкриється на `http://localhost:8501`.

## Задача, яку виконує агент

Аналіз completion rate курсів + ширший контекст (дохід, залучення, аудиторія),
щоб можна було ставити різні питання типу "які курси найпопулярніші" чи
"скільки ми заробили на місячних підписках".
